SDK 2.0: an ESM-only rewrite with a typed browser client, plugins, and new `./react`, `./next`, `./server` and `./proxy` entries. The browser client batches events, keeps visitors without cookies, honours consent and opt-out, and reads its options from `NEXT_PUBLIC_RA_CONFIG`, `PUBLIC_RA_CONFIG` or `VITE_RA_CONFIG`. `./react` adds `AnalyticsProvider`, `useAnalytics`, `TrackClick`, `ErrorBoundary`, `useRoutePageviews` and `computeRoute`; `./next` adds the `Analytics` route adapter; `./server` adds `createServerAnalytics`, which forwards the visitor's IP and user agent and uses `waitUntil`; `./proxy` adds `createProxy` and `createPageCounter` for a same-origin ingest path.
