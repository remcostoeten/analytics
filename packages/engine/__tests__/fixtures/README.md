`GeoIP2-City-Test.mmdb` is MaxMind's test database from [maxmind/MaxMind-DB](https://github.com/maxmind/MaxMind-DB/tree/main/test-data), licensed under CC BY-SA 4.0. It holds a handful of documented test networks, such as `81.2.69.160`, so tests do not need the 65 MB GeoLite2 download.

`parity-batches.json` holds the events of the phase 2 parity test. `legacy-rows.json` is what the v1 ingest handler (`v1/packages/ingestion/src/handlers/ingest.ts`) stored for the same events on 2026-09-28: each event was sent to v1's `/ingest` as a 1.x payload, with `IP_HASH_SECRET` set to the test secret in `batch.ts` and `GEOIP_MMDB_PATH` pointing at the test database, into a PGlite database migrated with the engine's migrations. v2 code may not import v1, so the rows are recorded once rather than produced on every run. `meta.botReason` and `meta.botConfidence` are left out; v2 stores `bot_score` and `bot_reasons` instead.
