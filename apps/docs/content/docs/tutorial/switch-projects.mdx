The settings come from `.env.local`, so another project means another build. This last step adds a settings bar for the API, the project, a read token and a public key, and keeps them in `localStorage`. The result is the [example dashboard](/examples/dashboard) as it is in the repository.

## 2. Run the finished example

The finished app is in the repository, with tests for the URL state and the read hook:

```bash
git clone https://github.com/remcostoeten/analytics
cd analytics && bun install
bun run --cwd examples/dashboard dev
```

It opens on `http://localhost:3301`. [Read client](/docs/sdk/read-client) lists every read this dashboard did not use, such as `paths`, `retention` and `lifecycle`, and [Build a minimal dashboard](/docs/getting-started/minimal-dashboard) shows the same reads from a Next.js server component.
