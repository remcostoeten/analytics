The client sends a pageview on load and on every `pushState` navigation. The events in `Events` are sent from step 5, once the page has controls to click.

## 2. Check that events arrive

Reload `http://localhost:3301`, then open the project in the dashboard and pick **Realtime**. The pageview shows up within a few seconds.

If nothing arrives, check the browser's network tab for the `POST` to `/v2/events`. A `403` means `http://localhost:3301` is missing from the project's allowed origins. [Events do not arrive](/docs/troubleshooting/no-events) covers the other causes.

On a real site, send events through your own domain with the [proxy](/docs/guides/proxy), so ad blockers that block third-party hosts do not drop them.
