## 2. What the read returns

The same read against this site's own project:

<LiveRead read="stats" />

Each metric has a `value` and a `change`, the ratio against the previous period of the same length. `change` is `null` when that period had nothing to compare with, and the tile shows "new".

A `period` such as `7d` ends at the start of today in UTC, so today's visits are not counted yet. Use `between(from, to)` to read up to now. [Read client](/docs/sdk/read-client) lists every link and read.
