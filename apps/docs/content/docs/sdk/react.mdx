```tsx
export function Providers({ children }: { children: React.ReactNode }) {
  return <AnalyticsProvider client={analytics}>{children}</AnalyticsProvider>;
}
```

## `AnalyticsProvider`

```ts
AnalyticsProvider(props: { client: Analytics; children: ReactNode })
```

Makes the client from [`createAnalytics`](/docs/sdk/client) available to `useAnalytics`, `TrackClick`, `ErrorBoundary` and the [Next `<Analytics />`](/docs/sdk/next) component below it.

## `useAnalytics<Events>()`

```ts
useAnalytics<Events extends EventMap = EventMap>(): Analytics<Events>
```

Returns the client from the nearest provider, typed with your `Events` map. Outside a provider it returns a client that does nothing.

```tsx
const analytics = useAnalytics<Events>();

function onUpgrade() {
  analytics.track("signup", { plan: "pro" });
}
```

## `TrackClick`

```ts
TrackClick(props: { name: string; props?: Props; children: ReactElement })
```

Sends an event when its only child is clicked. It runs the child's own `onClick` first. It renders no element of its own.

```tsx
<TrackClick name="signup" props={{ plan: "pro" }}>
  <button>Upgrade</button>
</TrackClick>
```

## `ErrorBoundary`

```ts
ErrorBoundary(props: {
  fallback: ReactNode | ((error: unknown, reset: () => void) => ReactNode);
  tags?: Props;
  children: ReactNode;
})
```

Catches render errors below it and records each one with `captureError`, adding `tags` to the error. It then renders `fallback`. A function fallback receives the error and a `reset` that clears the failure and renders the children again.

```tsx
<ErrorBoundary
  tags={{ area: "dashboard" }}
  fallback={(error, reset) => <button onClick={reset}>Try again</button>}
>
  <Dashboard />
</ErrorBoundary>
```

## `useRoutePageviews(path, route)`

```ts
useRoutePageviews(path: string | null, route: string | null): void
```

Sends a pageview with the route template whenever `path` or `route` changes. Use it to write an adapter for a router other than Next.

- Pass the pathname with its query string as `path` to count a change of only the query.
- Pass `null` for `path` or `route` while the router is not ready. The pageview is held until both are set.
- Create the client with `pageviews: false`. Once a route is set, the default `pageviews` plugin stops sending, but it still sends its first pageview.

```tsx
function RouteTracker() {
  const { pathname, search } = useLocation();
  const params = useParams();
  useRoutePageviews(pathname + search, computeRoute(pathname, params));
  return null;
}
```

## `computeRoute(pathname, params)`

```ts
computeRoute(pathname: string, params: { [name: string]: string | string[] | undefined } | null): string
```

Turns a pathname and the router's params into a route template.

- A segment equal to a param becomes `[name]`.
- The segments of an array param become `[...name]`.
- The splat params of React Router (`*`) and TanStack Router (`_splat`) become `[...splat]`.
- When the params cannot all be placed in the path, or `params` is `null`, the pathname comes back unchanged.

```ts
computeRoute("/blog/hello-world", { slug: "hello-world" }); // "/blog/[slug]"
computeRoute("/docs/a/b", { path: ["a", "b"] }); // "/docs/[...path]"
computeRoute("/files/a/b", { "*": "a/b" }); // "/files/[...splat]"
```
