```bash
npm install @spoar/sdk
```

```bash
bun add @spoar/sdk
```

Releases publish to the `latest` tag. 1.x is the separate `@remcostoeten/analytics` package.

The smallest working setup:

```ts
import { createAnalytics } from "@spoar/sdk";

export const analytics = createAnalytics({
  project: "example.com",
  key: "pk_live_...",
  endpoint: "/_ra",
});

analytics.track("hello");
```

An `endpoint` of `/_ra` sends nothing until that route exists. The [Quick start](/docs/getting-started/quick-start) covers the keys and the proxy route.

## Entries

| Import | Use it for | Exports |
| --- | --- | --- |
| `@spoar/sdk` | Any browser code | `createAnalytics`, `definePlugin`, types |
| `@spoar/sdk/plugins` | Opt-in features | Every plugin, each in its own file |
| `@spoar/sdk/react` | React apps | `AnalyticsProvider`, `useAnalytics`, `TrackClick`, `ErrorBoundary`, `useRoutePageviews`, `computeRoute` |
| `@spoar/sdk/next` | Next.js App Router | `<Analytics />` |
| `@spoar/sdk/server` | Route handlers and server actions | `createServerAnalytics` |
| `@spoar/sdk/proxy` | Serving the `/_ra` route | `createProxy`, `createPageCounter` |
| `@spoar/sdk/admin` | Scripts and CI with an API token | `createAdmin` |

Each entry has a page: [Options](/docs/sdk/options), [Client methods](/docs/sdk/client), [Plugins](/docs/sdk/plugins), [React](/docs/sdk/react), [Next](/docs/sdk/next), [Server](/docs/sdk/server), [Proxy](/docs/sdk/proxy) and [Admin](/docs/sdk/admin).
