---
title: Plugins
description: Opt-in features, each in its own file so an app only ships what it uses.
---

Import plugins from `@remcostoeten/analytics/plugins` and pass them in `plugins`, or add one later with `analytics.use(plugin)`:

```ts
import { createAnalytics } from "@remcostoeten/analytics";
import { errors, speedInsights } from "@remcostoeten/analytics/plugins";

export const analytics = createAnalytics({
  project: "example.com",
  key: "pk_...",
  endpoint: "/_ra",
  plugins: [speedInsights(), errors()],
});
```

Each plugin has its own page in the Plugins section, with its options, the events it sends and their props:

- [Overview](/docs/plugins): every plugin in one table, and how to write your own.
- [Groups](/docs/plugins/groups): companies, workspaces and teams as the `group:<type>` dimension.
- [Speed insights](/docs/plugins/speed-insights), [Errors](/docs/plugins/errors), [Experiments](/docs/plugins/experiments) and the rest are listed in the overview.
