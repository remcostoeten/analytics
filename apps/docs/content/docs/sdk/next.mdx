title: Next
description: The `<Analytics />` component, which sends App Router pageviews with route templates.
---

`@spoar/sdk/next` exports one component. [Next.js](/docs/frameworks/nextjs) has the full App Router setup: keys, the client, the provider, the `/_ra` route and server tracking.

```tsx
<AnalyticsProvider client={analytics}>
  <Analytics />
  {children}
</AnalyticsProvider>
```

## `<Analytics />`

| | |
| --- | --- |
| Props | None |
| Place it | Inside `AnalyticsProvider` from `/react`, in a Client Component |
| Sends | A pageview on every navigation, including a change of only the query string |
| Route | The template from `usePathname` and `useParams`, such as `/blog/[slug]`, so reports group by page type |
| Server rendering | Wraps itself in `Suspense`, because it reads `useSearchParams`, so static pages keep rendering on the server |

Create the client with `pageviews: false`, or every pageview is sent twice: once by the core and once by `<Analytics />`.
