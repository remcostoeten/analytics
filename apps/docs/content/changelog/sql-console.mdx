The docs homepage has a tools section with a read-only SQL console over this site's own project. Pick one of six queries (top pages, countries, sources, devices, Web Vitals and visitors per day) and it runs against the API, with the result shown as a table.

Each query is shown three ways: the SQL, the same read through `@spoar/client`, and a `curl` command. Copy whichever fits what you are building.

The console only runs these presets, never SQL typed by a visitor, because the SQL route stays closed to anonymous callers. The docs server holds a `sql` token for its own project and caches each answer for a minute. To write your own queries, open the [query page](/query) with a token of your own.
