---
title: Data is kept until you choose otherwise
description: Automatic deletion is now a switch per project, off by default.
date: 2026-11-22
label: improvement
docs: /docs/guides/self-host
---

Nothing is deleted automatically anymore unless an admin turns it on. Each project has an **Automatic deletion** switch under **Data retention** in its settings, off by default, with the number of days to keep next to it.

With the switch off, a project keeps all of its events, sessions, speed samples, logs and alert history. With it on, the nightly jobs permanently delete that project's rows older than the chosen days. Setting the days alone deletes nothing.

Projects that already had a retention other than the default 90 days had the switch turned on when the change shipped, since an admin chose those values. The API field is `retentionEnabled` on `PATCH /v2/projects/:project`.
